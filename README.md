# Aplikasi Pembelajaran Interaktif KPK dan FPB (Kelas VII SMP/MTs)

Aplikasi web interaktif berpendekatan visual dan pictorial yang dirancang khusus untuk siswa SMP/MTs Kelas VII dalam memahami konsep **Kelipatan Persekutuan Terkecil (KPK)** dan **Faktor Persekutuan Terbesar (FPB)**.

---

## ?? Fitur Utama

1. **Sequential Progression System**: Pembelajaran berbasis alur bertahap (Materi ? Simulasi ? Latihan ? Refleksi) dengan status tersimpan di `localStorage`.
2. **Visual & Pictorial Simulation**:
   - Simulasi lampu berkedip interaktif untuk menemukan KPK.
   - Simulasi pengelompokan buah interaktif untuk menemukan FPB.
3. **Interactive Worksheets (LKPD)**: Lembar kerja digital interaktif dengan umpan balik otomatis secara langsung.
4. **Interactive Quiz Engine**: 10 soal evaluasi pilihan ganda dan input angka dengan perhitungan nilai serta tingkat penguasaan otomatis.
5. **Fully Responsive Design**: Tampilan yang dioptimalkan untuk perangkat ponsel pintar, tablet, dan komputer.
